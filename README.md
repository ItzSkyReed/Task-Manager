# Task Manager
Реализовано в рамках тестового задания с разделением на Backend, Frontend и БД.


## Стек технологий

* **Backend:** C# 14, .NET 10, ASP.NET Core Minimal APIs, MediatR, FluentValidation, Entity Framework Core, JWT + Refresh Tokens (HttpOnly Cookie), Scalar (вместо Swagger).
* **Frontend:** Angular, Angular Material, Nginx (раздача и reverse proxy).
* **Database:** PostgreSQL 18.
* **Инфраструктура:** Docker, Docker Compose.

## Запуск

Для запуска требуется Docker.

1. **Клонируйте репозиторий и перейдите в его корневую папку:**
   ```bash
   git clone https://github.com/ItzSkyReed/Task-Manager.git
   cd TaskManager
   ```

2. **Настройте переменные окружения:**
   ```bash
   cp .env.example .env
   ```
   При необходимости измените `DB_PASSWORD` и `JWT_SECRET_KEY`. Если пропустить этот шаг, Docker использует значения по умолчанию из `compose.yaml`.

3. **Запустите приложение:**
   ```bash
   docker compose up -d --build
   ```

4. **Откройте приложение в браузере:**
   * **Веб-интерфейс:** [http://localhost:4200](http://localhost:4200)
   * **Документация API:** [http://localhost:8080/scalar/v1](http://localhost:8080/scalar/v1)

## Использование
- Регистрация и вход: при первом открытии http://localhost:4200 отобразится экран входа. Нажмите «Зарегистрироваться», укажите имя, email и пароль (минимум 8 символов) — после создания аккаунта произойдёт автоматический вход в приложение. Выйти из аккаунта можно кнопкой «Выйти» в правом верхнем углу.

### Вкладка «Проекты»:
- постраничный просмотр проектов с поиском по названию;
- создание и редактирование проекта через модальную форму («Создать проект» / иконка редактирования);
- удаление проекта (связанные с ним задачи удаляются каскадно).

### Вкладка «Задачи»:
- постраничный просмотр задач с поиском по названию и фильтрацией по статусу и проекту;
- создание задачи кнопкой «Создать задачу» (предварительно должен быть создан хотя бы один проект);
- просмотр подробной информации о задаче по клику на строку таблицы или иконку глаза;
- внутри карточки задачи доступны быстрая смена статуса (К выполнению, В работе, На проверке, Готово) и назначение/снятие исполнителя, а также переход в режим полного редактирования и удаление задачи.

### Вкладка «Пользователи»:
- постраничный просмотр пользователей с поиском по имени;
- добавление нового пользователя кнопкой «Добавить пользователя» (без смены текущей сессии);
- удаление пользователя (при удалении исполнителя задачи остаются в проекте без назначенного ответственного; при удалении собственного аккаунта выполняется автоматический выход).

## Структура проекта

- `backend/` - серверная часть на .NET 10 с разделением на слои (`Domain`, `Application`, `Infrastructure`, `API`).
- `frontend/` - клиент на Angular. Внутри `src/app/` код разбит на `core` (модели, сервисы, интерсепторы), `layout` (шапка и вкладки) и `features` (авторизация, проекты, задачи, пользователи). Для сборки и проксирования `/api/` используется Nginx.
- `compose.yaml` - запуск PostgreSQL, API и фронтенда в Docker.
